# Xyren AI Bot

Telegram AI chat bot using Google Gemini API (Python).

## Features
- Gemini se AI jawab
- Har user ke liye last 20 messages ki memory
- Daily message limit per user
- /reset se chat history clear

## Setup
1. `.env.example` ko copy karke `.env` banao aur apna Telegram token + Gemini API key daalo
2. `pip install -r requirements.txt`
3. `python bot.py`
